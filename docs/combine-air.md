# 조합의 공중 합류 표현

서로 다른 두 병종의 조합은 재료 두 마리가 각 위치 위로 떠오른 뒤 그 두 위치의 실제 중간점으로 모인다. 중앙에서 기존 모델이 생성한 성체 결과가 반짝이며 나타나고 바닥으로 내려온다. 화면 중앙을 고정 목표로 사용하지 않는다. 같은 병종의 기존 일반 합성은 유지한다.

## 권위와 표현

기존 `farm-merge-breed`의 재료 예약·취소·소모·결과 생성 규칙을 그대로 사용한다. PR406의 재료 먹이 예약 해제도 유지한다. 모델의 이동 경로나 결과 종류를 바꾸지 않고, 표현에 필요한 `combine` 효과 메타데이터와 반짝임 높이/시작 지연만 구분한다.

`features/farm-modes/combine/CombinePresentation`은 committed task와 원래 위치를 읽는다. 단일 주민 DTO의 display proxy에만 상승→이동→결과 착지 위치를 적용하며 별도 ghost actor를 만들지 않는다. approach 처음 32%에는 원래 위치 위로 상승하고 나머지 구간에 각 쌍의 중앙으로 이동한다. 재료는 권위 소모 시 사라지며 결과의 0.08초 등장 지연만 표현에서 숨긴다. 여러 쌍은 task별 중앙과 unit id로 구분한다.

최신 코드 얼굴과 neutral 몸 atlas는 그대로다. `displayUnit`의 최종 proxy를 몸·얼굴·눈입 socket이 같은 변환 행렬로 읽는다. 모델 높이/z는 그리기로 바꾸지 않는다. 기존 블랙홀은 조합 결과가 등장하면 닫고, 별도 merge-material ghost는 조합에서 그리지 않아 중복 외형을 막는다. task 취소·재료/결과 제거·씬 전환으로 parts가 사라지면 proxy cache도 제거한다.

막 성장한 주민을 바로 조합하면 조합 표시가 기존 성장 표시보다 우선한다. 성장 표시 cache를 제거해 높이를 이중 가산하거나 이전 성장 반짝임을 별도 위치에 남기지 않는다. 실제 모델의 성장 완료·조합 가능 여부는 지연하지 않는다.

효과와 task 메타데이터는 기존 내부 snapshot의 JSON 계약으로 보존한다. 일반 디스크 저장에는 연출 task를 추가하지 않으며, 소모 전/후 주민 진행만 기존 규칙대로 복원한다. 새로운 소모·재시도·성장 규칙은 없다.

## 타깃 검증

`npm run test:combine-air`는 실제 모바일 조합 버튼, 두 재료의 먹이 예약 해제, 취소/재료 제거/사망/씬 전환/결과 제거, 동시 두 쌍의 중간점·소켓·actor 중복 없음, sprite/vector 실제 제출, 6→5/10→8 및 병종별 2마리 보존, 소모 전후 내부 snapshot/rollback과 디스크 복원을 검사한다. 렌더 전후 전체 모델 snapshot도 같아야 한다.

immutable 기준 `00d64db715284c3719e5d5933ae82c0cb4dea6c5`의 merge owner와 전체 권위 상태를 비교한다. 효과만 제외하고 **foodRuntime을 포함**해 같아야 한다. 전체 게임 회귀는 이 기능의 완료 게이트로 추가하지 않는다.
