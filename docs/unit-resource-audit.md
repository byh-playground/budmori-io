# SVG resource integration audit

> Superseded for faces: the authored face groups, expression metadata, paint regions and per-expression sprite sheets described below were replaced by the code-drawn [face layer](./unit-face-layer.md). Body, clip and socket findings still apply.

Scope: ten troop SVGs, authored body/expression/paint/clip metadata and their presentation consumers. No SVG geometry was redesigned; simulation, input and saves are unchanged.

The new face and palette tests cover the codex representation as well as game selection; the browser contract covers both production code settings, overlap, independent phases, native sockets and exact authoritative state. This is a targeted audit, not a claim that every decorative resource in the repository is obsolete-free.

Additional source audit:

- `barley.svg` hungry left highlight: eye centre `(445.6,114.2)`, radius 6.5; old highlight `(436,112)`, radius 1.5 was detached. Only highlight X moves to 444.7, matching the right eye's small upper-left inset. Tests enforce both highlights inside their eyes. Source provenance is refreshed; the body outline/physics dimensions do not change.
- `assets/seed.svg`: the old 64x64 image had no tracked source or manifest references. Current dropped/growing seedlings use the troop sprout source. Remove the unused file, preserving that source.
- Boss prewarm: replace hardcoded `species-3` with the current `BOSS_SPECIES=9` contract. Keep ten boss asset variants for saved/legacy species restoration and native dynamic poses. Their second compile preset is intentional higher-detail boss art, not another hand-drawn copy.
- Focused/attack cheeks: nine species' existing action groups omit cheek shapes, while sprout retains them. Named cheek colour therefore disappears on those faces; the element icon remains. This is an art-contract question, not atlas bleed. A consistent resource solution would reuse the authored neutral cheeks within mutually exclusive action face groups with unique IDs/named regions. This candidate does not silently redesign those faces or restore an overlay.
- Growing seedlings' fed/mood DTO: unit feeding and growth meals are separate. Whether early meals should clear hungry mood is left to the separate growth follow-up; no model rules change here.
