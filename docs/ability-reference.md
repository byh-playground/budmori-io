# 병종 특성 현재 효과

이 문서는 `node scripts/ability-reference.mjs`로 생성합니다. UI와 동일한 기능 정의·표현을 사용합니다.
공통 스탯과 별도로 투자해야 해금하며, 각 능력의 강화와 적용 등급 완화는 독립된 경로입니다.
쌀·밀·보리의 역할은 확정이며 세부 수치는 현재 초기 조정값입니다. 밤톨의 피해·주기와 땅콩·호두 수치도 초기 조정값입니다.
공통 포인트·전투 중 잠금·저장 정책은 [스탯 계약](unit-stats.md)을 참고하세요.

## 콩 · 콩 분열

전투에서 쓰러지면 전투 한정 콩을 생성합니다. 생성된 콩은 다시 분열하지 않으며 전투 종료 시 제거됩니다.

해금: Rare (T3). 적용 등급: Rare (T3) → Uncommon (T2) → Common (T1).

| 단계      | 실제 효과                          |
| --------- | ---------------------------------- |
| 기본 해금 | 전투 사망 시 같은 종 T1 2마리 생성 |
| 강화 1    | 전투 사망 시 같은 종 T1 3마리 생성 |
| 강화 2    | 전투 사망 시 같은 종 T1 4마리 생성 |

## 옥수수 · 옥수수 알갱이 연사

한 기본 곡사 공격 주기 안에 알갱이를 시간차로 발사합니다.

해금: Rare (T3). 적용 등급: Rare (T3) → Uncommon (T2) → Common (T1).

| 단계      | 실제 효과                               |
| --------- | --------------------------------------- |
| 기본 해금 | 한 공격 주기 · 발사 2발 · 발당 ATK ×0.8 |
| 강화 1    | 한 공격 주기 · 발사 3발 · 발당 ATK ×0.8 |
| 강화 2    | 한 공격 주기 · 발사 4발 · 발당 ATK ×0.8 |
