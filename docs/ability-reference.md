# 종족 대표 능력 효과

이 문서는 종족별 기본 능력과 강화 수치를 정리합니다. node scripts/ability-reference.mjs로 생성합니다.
일반 병종 대표 능력은 Common(T1)부터 무료로 적용됩니다.
대표 능력의 수치와 강화 단계를 확인하세요. 공통 전투 스탯은 [병종 스탯](unit-stats.md)을 참고하세요.

## 콩 · 회복 기동

적 공격으로 강제 이동이 끝나면 2초 동안 이동 속도가 증가해요.

Common(T1)부터 자동 적용. 포인트로 효과를 강화합니다.

| 단계      | 실제 효과                       |
| --------- | ------------------------------- |
| 기본 능력 | 강제 이동 후 2초 이동 속도 +25% |
| 강화 1    | 강제 이동 후 2초 이동 속도 +35% |
| 강화 2    | 강제 이동 후 2초 이동 속도 +55% |

## 팥 · 연속 도약

가까운 적에게도 준비되면 도약해요. 공중에서는 지면 휩쓸기를 피하고, 착지 시 확률적으로 재사용 대기를 초기화해요.

Common(T1)부터 자동 적용. 포인트로 효과를 강화합니다.

| 단계      | 실제 효과                                         |
| --------- | ------------------------------------------------- |
| 기본 능력 | 가까운 적에게 도약 · 착지 후 도약 재사용 20% 확률 |
| 강화 1    | 가까운 적에게 도약 · 착지 후 도약 재사용 35% 확률 |
| 강화 2    | 가까운 적에게 도약 · 착지 후 도약 재사용 50% 확률 |
| 강화 3    | 가까운 적에게 도약 · 착지 후 도약 재사용 65% 확률 |

## 밤톨 · 대상 가시 연사

현재 공격 대상을 향해 3초마다 가시를 발사해요. 가시는 0.1초 간격으로 나가며 각각 공격력 100% 피해를 줘요.

Common(T1)부터 자동 적용. 포인트로 효과를 강화합니다.

| 단계      | 실제 효과                                        |
| --------- | ------------------------------------------------ |
| 기본 능력 | 3초마다 가시 1발 · 발당 공격력 100% · 0.1초 간격 |
| 강화 1    | 3초마다 가시 2발 · 발당 공격력 100% · 0.1초 간격 |
| 강화 2    | 3초마다 가시 3발 · 발당 공격력 100% · 0.1초 간격 |

## 땅콩 · 사망 분열

전투 중 사망하면 T1 분열체 2마리를 남겨요. 강화마다 분열체의 체력과 공격력이 각각 1.5배가 돼요.

Common(T1)부터 자동 적용. 포인트로 효과를 강화합니다.

| 단계      | 실제 효과                                   |
| --------- | ------------------------------------------- |
| 기본 능력 | 사망 시 T1 분열체 2마리 · 체력/공격력 ×1    |
| 강화 1    | 사망 시 T1 분열체 2마리 · 체력/공격력 ×1.5  |
| 강화 2    | 사망 시 T1 분열체 2마리 · 체력/공격력 ×2.25 |

## 호두 · 방어와 반격

5초마다 2초간 방어력 50을 얻어요. 방어 중 받은 RAW 피해를 모아 다음 망치에 100/150/225% 추가하며 공격력의 3배까지 적용해요.

Common(T1)부터 자동 적용. 포인트로 효과를 강화합니다.

| 단계      | 실제 효과                                                 |
| --------- | --------------------------------------------------------- |
| 기본 능력 | 5초마다 2초 방어 · 방어력 +50 · 저장 RAW의 100% 추가 반격 |
| 강화 1    | 5초마다 2초 방어 · 방어력 +50 · 저장 RAW의 150% 추가 반격 |
| 강화 2    | 5초마다 2초 방어 · 방어력 +50 · 저장 RAW의 225% 추가 반격 |

## 옥수수 · 부착 알갱이 연쇄 폭발

기본 공격 뒤 알갱이가 대상에 붙어요. 첫 부착 1초 후부터 부착 순서대로 0.1초 간격 폭발하며 알갱이마다 발사자 공격력의 50/75/100% 피해를 줘요.

Common(T1)부터 자동 적용. 포인트로 효과를 강화합니다.

| 단계      | 실제 효과                                      |
| --------- | ---------------------------------------------- |
| 기본 능력 | 부착 1초 후 연쇄 폭발 · 알갱이마다 공격력 50%  |
| 강화 1    | 부착 1초 후 연쇄 폭발 · 알갱이마다 공격력 75%  |
| 강화 2    | 부착 1초 후 연쇄 폭발 · 알갱이마다 공격력 100% |

## 쌀 · 수확 낫

적이 체력을 잃을수록 쌀의 치명타 확률이 높아져요. 치명타 피해 배율은 공통 2배예요.

Common(T1)부터 자동 적용. 포인트로 효과를 강화합니다.

| 단계      | 실제 효과                                                   |
| --------- | ----------------------------------------------------------- |
| 기본 능력 | 잃은 HP 비율에 따라 치명타 확률 최대 +35%p · 치명타 피해 ×2 |
| 강화 1    | 잃은 HP 비율에 따라 치명타 확률 최대 +55%p · 치명타 피해 ×2 |
| 강화 2    | 잃은 HP 비율에 따라 치명타 확률 최대 +75%p · 치명타 피해 ×2 |

## 밀 · 밀의 전투 지휘

기본 공격을 발사할 때 35% 확률로 밀을 중심으로 범위 내 살아 있는 아군에게 3초 동안 공격 속도 효과를 줘요. 효과는 밀이나 오라 범위를 벗어나도 유지돼요.

Common(T1)부터 자동 적용. 포인트로 효과를 강화합니다.

| 단계             | 실제 효과                  |
| ---------------- | -------------------------- |
| 기본 능력        | 공격 속도 보너스 +50%      |
| 강화 1           | 공격 속도 보너스 +75%      |
| 강화 2           | 공격 속도 보너스 +112.5%   |
| 명령 반경 기본   | 주변 기본 공격 사거리 ×2   |
| 명령 반경 강화 1 | 주변 기본 공격 사거리 ×3   |
| 명령 반경 강화 2 | 주변 기본 공격 사거리 ×4.5 |

## 보리 · 도리깨 갑주 파쇄

도리깨 기본 공격이 적중하면 방어도를 고정 수치만큼 낮춰요. 각 적중의 감소가 따로 만료돼요.

Common(T1)부터 자동 적용. 포인트로 효과를 강화합니다.

| 단계      | 실제 효과                                                      |
| --------- | -------------------------------------------------------------- |
| 기본 능력 | 기본 공격 적중 후 방어도 1 감소 · 감소마다 3초 · 방어도 최저 0 |
| 강화 1    | 기본 공격 적중 후 방어도 2 감소 · 감소마다 3초 · 방어도 최저 0 |
| 강화 2    | 기본 공격 적중 후 방어도 3 감소 · 감소마다 3초 · 방어도 최저 0 |
