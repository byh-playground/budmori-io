# 종족 대표 능력 효과

이 문서는 종족별 기본 능력과 강화 수치를 정리합니다. node scripts/ability-reference.mjs로 생성합니다.
기본 능력은 Common에서 제공하고, 다른 능력은 해금과 등급 조건을 따릅니다.
대표 능력의 수치와 강화 단계를 확인하세요. 공통 전투 스탯은 [병종 스탯](unit-stats.md)을 참고하세요.

## 콩 · 콩 분열

전투에서 쓰러지면 전투 한정 콩을 생성합니다. 생성된 콩은 다시 분열하지 않으며 전투 종료 시 제거됩니다.

해금: Rare (T3). 필요 등급: Rare (T3) → Uncommon (T2) → Common (T1).

| 단계      | 실제 효과                          |
| --------- | ---------------------------------- |
| 기본 해금 | 전투 사망 시 같은 종 T1 2마리 생성 |
| 강화 1    | 전투 사망 시 같은 종 T1 3마리 생성 |
| 강화 2    | 전투 사망 시 같은 종 T1 4마리 생성 |

## 콩 · 회복 기동

적 공격으로 강제 이동이 끝나면 2초 동안 이동 속도가 증가합니다.

Common 기본 능력으로 제공. 해당 능력의 강화 노드는 아래에서 구매합니다.

| 단계      | 실제 효과                               |
| --------- | --------------------------------------- |
| 기본 능력 | 적 공격으로 강제 이동 후 이동 속도 +25% |
| 강화 1    | 적 공격으로 강제 이동 후 이동 속도 +35% |
| 강화 2    | 적 공격으로 강제 이동 후 이동 속도 +55% |

## 옥수수 · 옥수수 알갱이 연사

한 기본 곡사 공격 주기 안에 알갱이를 시간차로 발사합니다.

해금: Rare (T3). 필요 등급: Rare (T3) → Uncommon (T2) → Common (T1).

| 단계      | 실제 효과                               |
| --------- | --------------------------------------- |
| 기본 해금 | 한 공격 주기 · 발사 2발 · 발당 ATK ×0.8 |
| 강화 1    | 한 공격 주기 · 발사 3발 · 발당 ATK ×0.8 |
| 강화 2    | 한 공격 주기 · 발사 4발 · 발당 ATK ×0.8 |

## 옥수수 · 팝콘 연쇄 폭발

착탄한 알갱이가 잠시 뒤 폭발하고, 주변 팝콘과 닿으면 즉시 연쇄 폭발합니다.

해금: Rare (T3). 필요 등급: Rare (T3) → Uncommon (T2) → Common (T1).

| 단계      | 실제 효과                                                                     |
| --------- | ----------------------------------------------------------------------------- |
| 기본 해금 | 착탄 1초 후 · 팝콘 접촉 즉시 연쇄 · 피해 ATK ×0.5 · 반경 기본 사거리 ×0.25 ×1 |
| 강화 1    | 착탄 1초 후 · 팝콘 접촉 즉시 연쇄 · 피해 ATK ×1 · 반경 기본 사거리 ×0.25 ×1.5 |
| 강화 2    | 착탄 1초 후 · 팝콘 접촉 즉시 연쇄 · 피해 ATK ×1.5 · 반경 기본 사거리 ×0.25 ×2 |

## 밤톨 · 밤톨 가시 부채

목표를 향해 부채꼴 가시를 발사합니다.

해금: Rare (T3). 필요 등급: Rare (T3) → Uncommon (T2) → Common (T1).

| 단계      | 실제 효과                                                      |
| --------- | -------------------------------------------------------------- |
| 기본 해금 | 목표 방향 부채꼴 90° 3발 · 발당 ATK ×0.5 · 기본 공격 4주기마다 |
| 강화 1    | 목표 방향 부채꼴 90° 5발 · 발당 ATK ×0.5 · 기본 공격 4주기마다 |
| 강화 2    | 목표 방향 부채꼴 90° 7발 · 발당 ATK ×0.5 · 기본 공격 4주기마다 |

## 팥 · 연속 도약

가까운 적에게도 준비되면 도약합니다. 공중에서는 지면 휩쓸기를 피하고, 착지 시 확률적으로 재사용 대기를 초기화합니다.

Common 기본 능력으로 제공. 해당 능력의 강화 노드는 아래에서 구매합니다.

| 단계      | 실제 효과                      |
| --------- | ------------------------------ |
| 기본 능력 | 착지 후 도약 쿨다운 초기화 20% |
| 강화 1    | 착지 후 도약 쿨다운 초기화 35% |
| 강화 2    | 착지 후 도약 쿨다운 초기화 50% |
| 강화 3    | 착지 후 도약 쿨다운 초기화 65% |

## 팥 · 착지 충격파

도약 착지 지점에서 기본 공격력과 사거리 기준의 충격파를 냅니다.

해금: Rare (T3). 필요 등급: Rare (T3) → Uncommon (T2) → Common (T1).

| 단계      | 실제 효과                                    |
| --------- | -------------------------------------------- |
| 기본 해금 | 충격파 피해 ATK ×1 · 반경 기본 사거리 ×1     |
| 강화 1    | 충격파 피해 ATK ×1.5 · 반경 기본 사거리 ×1.5 |
| 강화 2    | 충격파 피해 ATK ×2 · 반경 기본 사거리 ×2     |

## 땅콩 · 분리 협공

하나의 본체와 체력을 공유하는 두 알이 정해진 시점에 번갈아 타격합니다. 기절·사망·전투 종료 시 공격을 중단합니다.

해금: Rare (T3). 필요 등급: Rare (T3) → Uncommon (T2) → Common (T1).

| 단계      | 실제 효과                                           |
| --------- | --------------------------------------------------- |
| 기본 해금 | 한 공격 주기 3타 · 타격당 ATK ×0.5 · 넓은 협공 궤적 |
| 강화 1    | 한 공격 주기 4타 · 타격당 ATK ×0.5 · 넓은 협공 궤적 |
| 강화 2    | 한 공격 주기 5타 · 타격당 ATK ×0.5 · 넓은 협공 궤적 |

## 호두 · 웅크리기 반격

공격 회복 후반에 웅크려 첫 피격의 자기 피해와 넉백을 줄입니다. 방어 성공 후 다음 내려찍기를 한 번 강화합니다.

해금: Rare (T3). 필요 등급: Rare (T3) → Uncommon (T2) → Common (T1).

| 단계      | 실제 효과                                                                               |
| --------- | --------------------------------------------------------------------------------------- |
| 기본 해금 | 첫 방어 피격 피해 −25%·넉백 −50% · 다음 공격 ATK ×1.5 · 충격파 반경 기본 사거리 ×0.5    |
| 강화 1    | 첫 방어 피격 피해 −25%·넉백 −50% · 다음 공격 ATK ×1.75 · 충격파 반경 기본 사거리 ×0.625 |
| 강화 2    | 첫 방어 피격 피해 −25%·넉백 −50% · 다음 공격 ATK ×2 · 충격파 반경 기본 사거리 ×0.75     |

## 쌀 · 수확 낫

적이 체력을 잃을수록 쌀의 치명타 확률이 높아집니다. 치명타 피해 배율은 공통 2배입니다.

Common 기본 능력으로 제공. 해당 능력의 강화 노드는 아래에서 구매합니다.

| 단계      | 실제 효과                                                   |
| --------- | ----------------------------------------------------------- |
| 기본 능력 | 잃은 HP 비율에 따라 치명타 확률 최대 +35%p · 치명타 피해 ×2 |
| 강화 1    | 잃은 HP 비율에 따라 치명타 확률 최대 +55%p · 치명타 피해 ×2 |
| 강화 2    | 잃은 HP 비율에 따라 치명타 확률 최대 +75%p · 치명타 피해 ×2 |

## 밀 · 밀의 전투 지휘

기본 공격을 발사할 때 35% 확률로 밀을 중심으로 범위 내 살아 있는 아군에게 3초 동안 공격 속도 효과를 줍니다. 효과는 밀이나 오라 범위를 벗어나도 유지됩니다.

Common 기본 능력으로 제공. 해당 능력의 강화 노드는 아래에서 구매합니다.

| 단계             | 실제 효과                |
| ---------------- | ------------------------ |
| 기본 능력        | 공격 속도 보너스 +50%    |
| 강화 1           | 공격 속도 보너스 +75%    |
| 강화 2           | 공격 속도 보너스 +112.5% |
| 명령 반경 기본   | 밀 기본 공격 사거리 ×2   |
| 명령 반경 강화 1 | 밀 기본 공격 사거리 ×3   |
| 명령 반경 강화 2 | 밀 기본 공격 사거리 ×4.5 |

## 보리 · 도리깨 갑주 파쇄

도리깨 기본 공격이 적중하면 방어도를 고정 수치만큼 낮춥니다. 각 적중의 감소가 따로 만료됩니다.

Common 기본 능력으로 제공. 해당 능력의 강화 노드는 아래에서 구매합니다.

| 단계      | 실제 효과                                                      |
| --------- | -------------------------------------------------------------- |
| 기본 능력 | 기본 공격 적중 후 방어도 1 감소 · 감소마다 3초 · 방어도 최저 0 |
| 강화 1    | 기본 공격 적중 후 방어도 2 감소 · 감소마다 3초 · 방어도 최저 0 |
| 강화 2    | 기본 공격 적중 후 방어도 3 감소 · 감소마다 3초 · 방어도 최저 0 |
