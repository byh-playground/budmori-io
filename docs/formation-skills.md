# 편성 스킬

종별 패시브와 별개의 9종 자동 스킬이며, 탑에서 얻는 한 판짜리 유물입니다. 탑의 유물 문에서 새 유물을 얻거나
이미 가진 유물을 1레벨 올립니다. 한 판에 최대 3종, 유물당 최대 Lv.5(임시 값)이며 런이 끝나면 모두 사라집니다.
영구 습득·슬롯·장착·XP 포인트 소비는 없습니다. 유물은 그 판의 모든 층 전투에 자동으로 적용됩니다.

## 승인된 공격 유물 수치 · 0.67.2

요구: 층이 높아져도 공격 유물이 무의미해지지 않되, 체력 비례 피해만으로 전투를 해결하지 않는다.
사용자와 수치를 사전 검토하고 아래 여섯 공격 유물부터 적용했다. 기준은 현재 게시된 작업 공간이며,
공격 6종의 피해 수치를 먼저 승인했고, 이어 거대화와 치유 수치를 별도로 승인했다. 양 진영 치유와 보스 명중 계열 네 유물의 발동 조건, 보스 거대화·운석·망치의 피해 문턱도 별도로 승인했다(AI-002·008).

```text
기본 피해 = 1층 기본 피해 × [1 + 0.05 × (현재 층 − 1)] × 2^(유물 레벨 − 1)
보스 기본 피해 = 위 기본 피해 × 0.25
방어 전 피해 = 기본 피해 + 대상 최대 체력 × 최대 체력 계수 + 대상 잃은 체력 × 잃은 체력 계수
```

| 공격 유물 | 1층 Lv.1 기본 피해 | 최대 체력 계수 | 잃은 체력 계수 |
| --------- | -----------------: | -------------: | -------------: |
| 낙뢰      |                 50 |             1% |              0 |
| 운석      |                100 |           0.5% |              0 |
| 유성우    |             총 125 |        총 0.5% |              0 |
| 망치      |                 50 |              0 |             1% |
| 우주선    |             총 100 |        총 0.5% |              0 |
| 뇌운      |              총 75 |              0 |        총 0.5% |

층의 계수는 20층 1.95, 40층 2.95다. 레벨 배율은 Lv.1–5에서 1/2/4/8/16이며
기본 피해에만 적용한다. 보스의 25%도 기본 피해에만 적용하고 체력 비례 계수는 양 진영이 공유한다.
낙뢰의 20층 Lv.5 기본 피해는 1,560, 40층 Lv.5는 2,360이며 보스는 각각 390/590이다.
여기에 대상 최대 체력의 1%를 더한 뒤 기존 방어·가드·받는 피해 감소를 적용한다.

유성우·우주선·뇌운은 한 번 발동할 때의 총 기본 피해와 비례 계수를 실제 타격 수로 나눈다.
기존 유성 수(5+레벨−1), 비행 유물 지속(5+레벨−1초)과 0.2초 간격은 유지하므로
Lv.5에는 유성 9개 또는 pulse 45회로 나눠 쓴다. 빗나간 몫을 다른 타격에 재분배하지 않는다.
광역은 각 적중 대상에게 따로 적용하며, 대상 전환도 남은 타격 예산 안에서 처리한다.

층·레벨·진영·분할 수로 정한 기본 피해/비례 계수는 시전 시 효과에 저장한다.
최대 체력과 잃은 체력은 매 타격 직전의 실제 대상 값을 읽는다. 체력이 가득 찬 대상의 잃은 체력 항은 0이다.
비행 유물의 잃은 체력 비례 총량은 1회 전체 계수의 합이며, 실제 회복·피격에 따라 각 타격의 체력 기준은 달라진다.
내부 checkpoint는 이 효과 필드를 보존한다. 판정·카드·획득 결과·HUD는 같은 수식과 정의를 읽는다(DEV-001·013).

기존 일반 공격의 등급 예산과 비교했지만 승인된 스킬 기본 피해에는 병력 공격력을 섞지 않는다(AI-003·004).
거대화·치유·복사와 보스의 피해 누적형 문턱은 아래 별도 절의 승인 내용을 따른다.

## 승인된 거대화·치유 · 0.67.2

거대화는 무작위 3명·10초를 모든 레벨에서 유지한다. 동작당 추가 피해는
`10 × [1 + 0.05 × (층 − 1)] × 2^(레벨 − 1)`이며 보스는 이 값의 25%다.
40층 Lv.5에서 아군 +472·보스 +118이다. 기존 공격력 배율은 제거하고 몸집(아군 3배·보스 1.25배),
방어 +25는 유지한다. 일반 병력도 몸집 변화와 공격 geometry가 같은 giantScale을 읽어 큰 팥의 착지 지점과 피해 범위가 어긋나지 않는다. 등급/성장 예산·공격 패시브·속성·치명타가 추가분을 다시 증폭하지 않는다.
대상 방어·받는 피해 감소는 적용하며, 실제 체력 손실의 원래 피해 몫만 충전에 기여한다.

추가 피해는 기본 공격 한 동작의 예산이다. 각 종의 정규화된 strike/shot weight로 나눠
연타/투사체 수가 늘어도 동일한 대상에게 적중한 추가분의 합을 유지한다. 근접/가시의 보조 대상은
기존 기본 공격의 보조 대상 배율을 따른다. 옥수수 후속 부착 폭발·보스 특수 패턴 등 별도 능력에는
추가 예산을 다시 부여하지 않는다. 공격 준비 시 추가 예산을 snapshot에 고정하므로 발사 후 만료·원본 사망에도
이미 발사한 투사체의 해당 예산은 보존한다. 분신은 생성할 때 거대화 상태를 복사하지 않는다.

치유의 비는 `100 × [1 + 0.05 × (층 − 1)] × 2^(레벨 − 1) + 원본 아군 평균 최대 체력 × 0.1`의
총 회복량을 1초 동안 부상자에게 분배한다. 보스는 기본 회복의 25%와 자신의 최대 체력 10%를 합친다.
40층 Lv.5는 아군 기본 4,720, 보스 기본 1,180이며 체력 비례 계수는 레벨/진영으로 다시 증폭하지 않는다.
평균 체력 기준은 시전 시 살아 있는 원본 아군이며 새싹·분신·분열체는 제외한다. 초과 회복 재분배와 빈 틱 몫 소멸은 유지한다.

실제로 회복한 대상의 id·세대를 효과 수명 동안 보존한다. 첫 틱에 체력이 가득 차도 1초의 상승 회복 연출은 이어지며,
도중에 회복받은 대상도 추가한다. 죽거나 세대가 바뀐 대상에는 그리지 않는다. 표현용 대상 기록이 회복량·분배·발동 문턱을 바꾸지 않는다.

치유 발동 문턱은 양 진영 모두 `Q = 총 회복량 H × 1.5`이며, 성공 시 충전 0·재사용 대기 5초다.
고정 200 문턱은 사용하지 않는다. 플레이어는 분신을 제외한 아군이 실제로 잃은 체력만 합산하고,
보스는 보스 본체들이 실제로 잃은 체력만 합산한다. 부하 피격·회복·유물 피해가 보스 본체의 게이지를 채우지 않는다.
하나의 계산에서 H/Q를 함께 구해 슬롯의 `healingTotal`/`required`로 유지하고 HUD·판정·checkpoint가 같은 값을 읽는다.
매 전투 틱과 실제 시전 판정에서 현재 생존 원본 아군/최대 체력을 갱신하므로 아군 사망·최대 체력 변경 시 문턱도 갱신된다.
보스는 대기 중에는 다음 준비가 가능한 본체, 준비 중에는 해당 시전자 본체의 최대 체력을 사용하며 방출 시 다시 확인한다.
여러 보스의 교체에도 별도 게이지 초기화 없이
현재 Q로 충전 상한을 맞추며, 준비 후 Q가 높아져 부족하면 충전을 소비하지 않고 다음 기회를 기다린다.
회복 효과는 성공한 방출 시 H를 snapshot하여 1초 동안 유지한다. 매번 충전에 1.5H 이상의 실피해가 필요하고 최대 H만 회복하므로,
이 유물 자체가 피해보다 많은 회복을 반복 생산하지 않는다. 추가 환급·감쇠·80% 상한·중첩 제한 규칙은 넣지 않는다.

예를 들어 무보정 1층 출발의 20층 Lv.5 보스는 H=1,867.1/Q=2,800.65,
40층 Lv.5 보스는 H=2,715.2/Q=4,072.8이다. 공격력·최대 체력 카드가 있으면 실제 본체 체력 기준으로 다시 계산한다.

## 승인된 보스 피해 문턱 · 0.67.2

요구: 후반에도 고정 문턱만으로 과도하게 자주 발동하지 않으면서, 체력이 적은 본체도 조건을 달성할 수 있어야 한다.
사용자에게 정확한 공식과 20/40층 예시를 먼저 제시하고 승인받아 아래 수치를 적용했다.
`S = 1 + 0.05 × (층 − 1)`이며, 문턱에는 유물 레벨 배율과 보스 위력 25%를 곱하지 않는다.

| 보스 유물 | 누적 조건            | 문턱                                          | 20층    | 40층    |
| --------- | -------------------- | --------------------------------------------- | ------- | ------- |
| 거대화    | 본체들이 준 실피해   | `min(200 × S, 시전자 본체 최대 체력 × 0.05)`  | 390     | 590     |
| 운석      | 본체들이 준 실피해   | `min(500 × S, 시전자 본체 최대 체력 × 0.1)`   | 975     | 1,475   |
| 망치      | 본체들이 받은 실피해 | `min(1,000 × S, 시전자 본체 최대 체력 × 0.1)` | 1,087.1 | 1,535.2 |

예시는 무보정 1층 출발·보스 체력 카드 없음이며, 20층 최대 체력 10,871, 40층은 본체당 15,352다.
망치는 부하 사망 대신 본체 피격으로 충전한다. 평타·범위·고유 공격의 실제 HP 손실을 합산하고,
부하가 주거나 받은 피해·부하 사망·회복·유물 피해는 위 세 보스 문턱에 기여하지 않는다.
여러 본체의 기여는 보스 공용 슬롯에 합산하되, 최대 체력 기준은 현재 시전자다.
준비 중에는 해당 시전자의 최대 체력을 사용하며, 본체 교체·최대 체력 변경·층 변경 시 문턱과 상한을 다시 계산한다.
내부 checkpoint는 현재 문턱·충전·쿨타임을 보존하고, HUD는 동일한 runtime 문턱과 정의의 공식을 표시한다.
성공 시 충전 0·재사용 대기 5초, 실패·중단 시 미소비 규칙은 유지한다.
플레이어 거대화·운석의 준 피해 200/250, 망치의 아군 쓰러짐 3회는 바꾸지 않는다.

## 출처와 소유권

Garden의 onCombatResolved Signal이 실제 HP 손실·적중·치명타·쓰러짐을 전달합니다.
FormationSkills가 편성 게이지·효과 수명을 소유하고 UnitCollection이 모든 복사체 추가·제거를 소유합니다.
피해와 적중은 일반 공격 및 기존 병종 능력을 포함합니다. 편성 스킬 피해/회복, 복사체와 그 투사체는
기여하지 않습니다. 거대화 고정 추가 피해는 실제 HP 손실에서 원래 피해/합산 피해 비율로 분리해
원래 몫만 조건에 넣습니다. 과잉 피해도 실제 HP 손실을 넘겨 충전하지 않습니다.
전투 시간 조건을 위한 공통 집계는 있지만 현재 9종에는 처치·수동 도약·시간 조건을 배정하지 않았습니다.

UnitCollection의 건강 Signal로 부상자 집합을 유지하므로 치유의 비가 매 틱 전체 병력을 스냅샷하지 않습니다.
밀집도·범위 적중·공중 분리는 기존 FixedSpatialGrid를 사용합니다. 원본 저장소와 고정 GameKit에는 별도
공중 soft-separation API가 없어 두 비행 스킬이 동일한 격자 기반 완만한 반발 경로를 공유합니다.
강제로 완전 비겹침을 보장하지 않습니다. 효과의 age·위치는 기존 GameKit presentation 보간으로 표시합니다.

## 복사와 버프 정책

사용자 인터뷰에서 복사는 밀집한 병력을 늘리는 유물로 유지하며, 원본별 생존 분신 수나 복사 횟수 제한은 두지 않기로 했다.
복사 대상에서 제외하는 것은 `isFormationClone`인 분신이다. 분신이 아닌 아군 소환체도 복사할 수 있다.
반복 발동 시 같은 원본을 다시 복사할 수 있으며, 원본/분신 연결 메타데이터로 대상 자격을 제한하지 않는다.
레벨별 범위·분신 체력 1·전투 종료까지의 수명·장면의 실행 개체 상한은 현재 값을 유지한다.

복사체는 현재/최대 HP 1이며 원본의 종·등급·기본 스탯·성장 모습·표정 seed와 해금된 병종 능력을 따릅니다.
거대화·밀 지휘·보리 방어 감소·공격 중 가드 등 임시 상태는 생성 시 복사하지 않습니다.
새 복사체가 나중에 독립적인 거대화 대상이 되는 것은 허용하며 버프는 원래 시각에 만료합니다.
복사체는 밀집도·재복사·모든 편성 조건에서 제외하고 사망 분열도 막습니다. 원본 사망이 복사체를
즉시 지우지는 않습니다. 고정 수명 없이 죽거나 전투가 끝날 때만 제거합니다.

## 병력 스킬의 기존 크기·초기값

- 복사 기본 반경: 원본 SVG 신체 정의의 T1 콩 몸통 지름 3배. 운석은 같은 3배, 유성우는 1배가 **바닥 값**이고, 병력의 운석·유성우는 겨냥한 몸의 그린 지름의 절반(`sizeScale` 0.8, `TARGET_SIZE_PROFILE`)이 이보다 크면 그 값을 쓴다. 그림과 피해 판정이 같은 반경을 읽으며, 작은 소환체를 겨냥해도 바닥 값 아래로 줄지 않는다.
- 운석은 적 중심에서 적 반경 + T1 지름 3배 이내의 면적 균등 무작위 지점을 택합니다.
  낙하 0.75초 전에 지점을 고정하며 후속 명중 보정은 없습니다. 유성우도 각 지점을 독립 고정합니다.
- 큰 운석 넉백은 기존 병력 넉백 5·들림 2를 재사용합니다. 거대 적도 수평 속도 5로 밀리고
  초당 지수 감쇠 6으로 감속하며 경기장 경계를 벗어나지 않습니다.
- 우주선/뇌운은 0.5초 등장 후 공격 시계를 시작하고, 0.5초 동안 떠나거나 흩어집니다.
  추적 속도 6, 공격/재탐색 거리 18, 공중 분리 거리 1.4입니다.
  우주선은 실제 아래 투영 지점의 적 한 명만 공격하고 빔 반경은 0.12입니다. 목표가 옆으로 빠지면 빗나갑니다.
  뇌운은 사거리 안의 목표에 곡선 아크로 타격합니다. 사망 시 재탐색하며 사거리 밖에서도 수명은 갑니다.
- 각 발동이 별도 개체를 추가합니다.
- 복사체 폭증 방지는 기존 장면별 전투 개체 예산에 임시 여유 2,000개를 더한 상한입니다.
  선택한 원본을 전부 복사할 여유가 없으면 부분 복사하지 않고 발동을 보류합니다.
- 치유는 실제 회복 총량을 고정하므로 일반 회복 배율로 총량을 추가 증폭하지 않습니다.
  틱의 남는 회복은 같은 틱의 다른 부상자에게 재분배하며 부상자가 없으면 그 시간 몫은 소멸합니다.

## 저장과 검증

유물은 한 판 안에서만 유효해 디스크에 저장하지 않습니다. 새로고침하면 그 판은 사라집니다.
전투 개체·복사체·게이지·버프·비행 개체 스냅샷도 디스크에 저장하지 않습니다.
내부 결정론 checkpoint만 별도 formationRuntime과 임시 Unit 필드를 보존합니다.

기본 PR 검증은 `tests/source-smoke.e2e.mjs`의 원본 ESM 시작과 실제 9종 혼합 전투입니다.
같은 흐름에 보스 광역의 대상별 충전, 카드 선택·다음 전투 덱 유지·재도전 초기화와 양 진영 5개 스킬의
공유 모델/표시 DTO 렌더를 확인합니다. 기존 `tests/smoke.e2e.mjs`의 상세 검증은 필요할 때 별도로 실행합니다.
개발 중 집중 모델·모션 검증은 임시로만 실행하고 결과를 PR에 남기며 영구 단위 테스트 파일은 추가하지 않습니다.

공식 GitHub CI의 Chromium은 SwiftShader를 사용합니다. source smoke는 원본 `index.html`과 ESM을 제공하고,
manifest에 고정된 CDN 모듈 요청을 같은 해시의 `vendor/upstream` 오프라인 파일로 가로챕니다.
라이브 CDN 가용성이나 실제 GPU/모바일 기기 검증과는 구분합니다. 모든 소스와 SVG는 번들 생성 없이
제품과 같은 파일을 읽으며, 스크린샷은 실제 RAF와 FarmSession 표시 DTO를 통과한 결과입니다.

## 양 진영의 공통 카드와 기술 HUD

탑 강화층의 유저 카드 선택 성공 뒤, 보스도 같은 `rollCardOffers`로 스탯·패시브·스킬 후보 3장을 만들고 동등 확률로 1장을 자동 선택한다. 정의, 종류 가중치 8:1:1, 희귀도, 중복 강화·상한을 공유한다. 명시적 제외는 복사 스킬과 불사 패시브뿐이다. 스킬은 최대 3종·각 5레벨, 스탯/패시브는 카드별 10장이다. 슬롯이 가득 차도 스탯·패시브는 계속 나오고 스킬만 보유 기술 강화로 제한한다. 전체 풀이 소진되면 카드 없음으로 안내하며 진행 입력을 막지 않는다. 이벤트 문은 보스 카드 획득을 발생시키지 않는다.

`applyTowerCard`가 획득을 한 번 확정하고, receipt에는 후보·선택 index·시작/종료 시각과 양 진영 획득의 실제 전후 값, 후보를 만들기 전 상태를 기록한다. UI는 기존 doorCard 영역에서 총 1.8초 안에 내 획득 확인 → 보스 후보 → 선택 강조 → 실제 변화 순으로 보여준다. 별도 타이머나 UI가 모델을 다시 적용하지 않는다. 이 동안 다음 문 입력은 모델에서도 잠긴다. 새 도전은 양쪽 카드를 초기화하며 높은 층 직접 시작도 기존 유저 흐름처럼 빈 덱이다. 농장에는 적용하지 않는다.

보스 본체와 일반 소환 부하는 같은 enemy 진영이다. 스탯은 같은 Unit의 statModifiers, 패시브는 같은 합산/조건 함수로 적용한다. enemy는 player 전역 카드가 적용되지 않은 원본 병종 스탯을 읽는다. 부하 사망은 복수·도우미에 기여하지만 본체 피격형 보스 망치를 충전하지 않는다. 플레이어 망치는 기존 아군 사망 조건을 유지하며 복제 분신과 사망 분열 자식의 반복 충전은 제외한다. 전투별 사망 누적은 다음 전투에 초기화한다. 피해/적중/치명/피격 이벤트는 진영 소유권을 분리하며 스킬 피해는 스킬 조건을 충전하지 않는다.

스킬 model/presentation은 하나이며 차이는 definition의 역할 profile 값이다. 아래 수치는 초기 구현 조정값이지 사용자 확정 밸런스나 실기기 난이도 검증값이 아니다.

| 항목                  | 보스 profile / 공통 규칙                                                                                   |
| --------------------- | ---------------------------------------------------------------------------------------------------------- |
| 거대화                | 준 실피해 `min(200×S, 시전자 최대 체력 5%)`, 무작위 3명·10초, 몸집 1.25배·방어 +25, 추가 피해는 아군의 25% |
| 낙뢰                  | 본체 실제 적중 15회, 고정 착점 0.7초 예고 뒤 광역                                                          |
| 운석                  | 준 실피해 `min(500×S, 시전자 최대 체력 10%)`, 공유 낙하/착탄                                               |
| 유성우                | 본체 실제 적중 30회, 공유 낙하/발사 간격                                                                   |
| 우주선                | 30점: 명중 +1·치명타 추가 +2, 실제 판정 빔·최대 3명                                                        |
| 뇌운                  | 본체 실제 적중 25회, 큰 구름 하나에서 최대 3명으로 분기                                                    |
| 치유의 비             | 기본 회복은 아군의 25% + 시전자 최대 체력 10%, 1초 분배, 문턱은 실제 총 회복량의 1.5배                     |
| 거대 망치             | 본체가 받은 실피해 `min(1,000×S, 시전자 최대 체력 10%)`, 기절 1초                                          |
| 비율 재생·흡혈·도우미 | 공통 카드 값의 0.25배, 고정량 재생은 기존 값                                                               |

몸체 radius/height와 공격 geometry는 별개다. 거대화 배율은 실모델 몸체와 실제 렌더에 같이 반영한다. 명중은 실제 피격 대상마다 합산하며 한 동작당 1회 제한을 두지 않는다. 보스 본체 여러 마리의 평타·범위·고유 공격을 합산하고 일반 소환 부하의 명중은 제외한다. 플레이어의 낙뢰/유성우/뇌운 50/100/75회와 우주선 치명타 10회는 유지한다. 보스는 낙뢰/유성우/뇌운 15/30/25회, 우주선 30점(명중당 +1·치명타 추가 +2)이다. 유물 피해는 어느 진영의 유물도 충전하지 않는다.

### 공격 스킬의 크기 기준 (0.41.6)

공통 profile의 `sizeReference`가 병력은 대상(`target`), 보스는 시전자(`caster`)를 선택한다. 보스의 초기 `sizeScale=0.8`에 대해 `D = 시전자 현재 몸체 반경 × 2 × 0.8`을 기준 직경으로 사용한다. 이는 이번 구현의 초기 조정값이다. Unit의 현재 radius/height는 이미 거대화를 반영하므로 배율을 다시 곱하지 않는다. 피격 대상이 작아져도 보스 공격 크기는 줄어들지 않는다.

- 낙뢰의 예고·피해 원 반경은 D/2이며, 번개 시각 크기도 같은 기준에서 나온다. 착점 고정·0.7초 예고·회피 규칙은 유지한다.
- 우주선의 원반 기준 폭과 레이저 전체 판정 폭은 D이다. 피해 검색에는 전체 폭의 절반을 반경으로 사용한다. 본체가 빔 위에 그려지는 기존 레이어 순서는 유지한다.
- 운석과 유성우의 각 착탄 피해 원 반경은 D/2이며 그림은 이 실제 radius를 읽는다. 흩뿌림은 D/2에 실제 피격 대상 반경을 더한 기존 무작위 배치 계약을 쓴다.
- 뇌운의 안정된 구름 기준 폭은 D, 대상 검색 반경은 D/2이다. 검색 원 전체가 광역 피해를 입는 것은 아니며 최대 세 대상을 고른 뒤 기존 분기 번개로 개별 타격한다. 등장·소멸의 구름 퍼짐은 안정된 폭보다 클 수 있다.

거대 망치도 같은 기준을 쓴다. 병력의 망치는 내려치는 대상 몸체만큼, 보스의 망치는 보스 자신의 크기(D 기준 `CASTER_SIZE_PROFILE`)로 그려지고, 망치가 내려앉는 높이는 맞는 대상의 몸체 윗면이다. 낙뢰의 충격 고리는 맞은 몸체 반경의 1.6배에서 멈춘다(착점 판정 반경을 넘어 경기장 전체로 퍼지지 않는다).

치유의 비의 구름 높이·줄기 간격·낙하 높이는 치료받는 몸의 반경·높이에 비례한다. 밤톨 가시 조각과 옥수수 심의 그림은 티어 1 몸 기준으로 맞춘 크기에 발사한 몸의 티어와 거대화 배율을 곱한다(거대화 배율은 발사 때 탄에 `chestnutGiant`·`cornGiant`로 기록하고, 보통 크기면 필드가 없다). 옥수수 심의 충돌 높이는 단계마다 고정이라 그림 배율의 근거로 쓰지 않는다. 옥수수 탄은 껍질 잎까지 포함한 그림 전체가 쏜 옥수수 자신의 몸 높이를 넘지 않는다. 타격 불꽃(일반·원소)은 타격 세기로 모양을 정하고, 크기는 때린 몸의 반경으로 `bodyScale`을 곱한다(보스가 때리면 보스 몸 기준). 피해 판정·충돌은 바꾸지 않는다.

위치·머리 연결 높이는 여전히 실제 피격 대상의 몸체를 읽는다. 시각 크기 참조와 대상 부착 좌표를 분리하며, 해석된 크기를 실제 효과와 FarmSession DTO로 전달한다. 병력의 기존 대상 크기 시각·고정 판정 반경은 바꾸지 않고 위력·조건·쿨·대상 수 역시 유지한다.

양 진영은 효과 발동 성공 시점부터 슬롯별 5초 쿨타임을 공유한다. 쿨 중 조건 충전은 허용하지만 조건·쿨 종료를 모두 만족해야 발동한다. 보스는 물리 패턴 뒤 준비0.8초→발동→회복0.45초 동안 자발 이동·평타와 새 시전을 멈춘다. 발동 전 기절·사망은 충전/쿨 소비 없이 취소하며, 기존 UFO/뇌운의 지속효과는 유지된다. 전투 종료에는 효과와 버프를 정리한다.

보스 HP 아래와 유저 HUD는 같은 RelicDock의 아이콘·충전바·쿨 부채꼴·ready 표현을 쓴다. 실제 runtime 조건량과 prepare/recover 상태를 읽고 터치 상세에서 효과·조건·남은 시간을 표시한다. 가짜 발동 타이머는 만들지 않는다. 카드 화면 역시 기존 테마/선택 컴포넌트를 재사용하고 독립 흰색 패널은 제거했다.

기존 디스크 저장 0.30~0.41은 유지하며 진행 중인 탑은 원래처럼 디스크 복원하지 않는다. 내부 snapshot에는 거대화 배율/대상 세대와 공통 Unit 상태를 보존한다. 버프·회복의 기존 편성 병력(대기 포함) 범위는 유지하고 공격 대상만 현재 전장의 combatUnits로 제한한다.

공식 source smoke는 모든 기능·UI 상태 assertion을 기본 실행한다. 이미 검토한 화면의 중복 저장은 기본 생략하고, 필요한 렌더 검토에만 같은 스크립트의 `BUDMORI_CAPTURE_SHARED_HUD=1` 옵션으로 PC HUD 이미지를 저장한다. 이미지 저장 여부가 실전 스킬·DTO·모바일 레이아웃 검증을 끄지는 않는다.

0.41.6의 크기 검증은 같은 혼합 전투 안에서 다섯 보스 기술의 중심·범위 안팎 실제 피해와 실제 표시 DTO를 확인한다. 대표 이미지는 `BUDMORI_CAPTURE_BOSS_SCALE=ufo`, `lightning`, `all`로 선택하며, 이미 검토한 동일 제품의 반복 실행은 `0`으로 이미지 저장만 생략할 수 있다. 기존 기능 assertions는 동일하게 실행한다.

## 카드 선택의 단계별 피드백 (0.41.7)

같은 카드 레일에서 내 선택이 확정됐음을 먼저 보여준 뒤 보스 차례로 이어진다. 초기 시간 배분은 0~0.2초 내 획득, 0.2~0.55초 보스 후보 세 장, 0.55~0.75초 선택 한 장 강조, 0.75~1.8초 실제 변화다. 총 잠금 시간은 기존 1.8초를 늘리지 않으며 확인 버튼·가짜 재추첨·별도 독립 패널을 추가하지 않는다. 애니메이션 종료 이벤트는 카드 적용이나 입력 잠금 해제의 근거가 아니다.

스탯과 패시브는 이번 획득량과 해당 카드 누적 보너스의 전후 값을 구분한다. 다음 보스의 기본값을 모르는 문 선택 화면에서 최종 절대 스탯을 추정해 표시하지 않는다. 보스 profile의 비율 보정과 기존 formatter를 공유한다. 기술은 새 기술 또는 이전/새 레벨 및 실제 효과 변화로 설명한다. 다음 문에는 마지막 획득 요약을 유지하고, 다음 전투 보스 기술 슬롯에는 신규·강화 표시를 한 번만 보여준다. 이는 시각 피드백이며 충전·쿨·시전 조건을 바꾸지 않는다.

receipt serial 한 건은 양 진영의 카드 확정 한 번을 나타내며 UI는 그 결과만 읽는다. 잠금 중 반복 입력·화면 크기 변경·메뉴 이탈은 재추첨이나 재적용을 만들지 않는다. 새 도전에는 결과와 기술 강조가 남지 않는다. reduced motion에서는 이동·확대 대신 텍스트·체크·고정 테두리로 같은 단계와 결과를 보여준다.

## 시전 적격성과 실패 양보 (0.41.8)

보스는 준비 전에 부작용 없는 공통 `canCast`를 검사한다. 공격 기술은 기존 적 대상 조회를, 치유는
기존 부상 아군 집합을, 거대화는 아직 거대화하지 않은 아군을 사용한다. 복사는 별도 절의 단순한 대상 규칙을 따른다.
준비 중 대상 사망·이동·회복·버프 변경이 생길 수 있으므로 방출 직전에 다시 검사한다. 실패하면
충전과 쿨은 소비하지 않고 가짜 회복 동작도 만들지 않는다. 그 틱과 다음 적격 행동 선택에서 실패한
슬롯을 한 번 건너뛰어 다른 기술·물리 공격·추격에 양보한다. 이는 새 쿨이나 HUD 타이머가 아니며
성공 시에만 기존 5초 쿨과 0.45초 회복을 시작한다. 재시도 표식은 전투 종료에 정리되고 snapshot에 보존한다.

검토된 카드 결과 사진의 재저장은 `BUDMORI_CAPTURE_CARD_FEEDBACK=1`에서만 수행한다. 기본 실행에서도 실제 입력·4단계·결과·배지 초기화와 CSS 종료 관측은 유지한다.
