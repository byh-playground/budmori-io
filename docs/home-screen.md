# 메인 화면과 복귀

0.67.10의 메인 화면은 설정 → **메인 화면으로**에서 접근합니다. 기존 `setHome`·hash 라우트를 재사용하며 별도 화면 상태를 추가하지 않습니다(DEV-001).

| 동작                    | 기대 결과                                                                     |
| ----------------------- | ----------------------------------------------------------------------------- |
| 처음 방문               | 새 농장 시작이 주요 버튼, 비활성 이어가기 노출 없음                           |
| 저장된 농장이 있음      | 이어가기 우선, 병력 수·최고층 표시. 화면 조회만으로 농장을 새로 복원하지 않음 |
| 농장/도전 → 설정 → 메인 | 진행 저장 요청, 메뉴 닫기, 입력 중단, 같은 세션 일시정지, URL `#/`            |
| 메인 → 이어가기         | 같은 농장/도전 인스턴스 재개, 논리 시계 기준 재설정, `#/farm`                 |
| 뒤로/앞으로             | `#/`, `#/farm`, `#/menu`의 실제 화면과 이력 일치. 이력 복원 시 push 없음      |
| 메인에서 F5             | 저장한 농장 진행 복원. 전투 장면은 기존 계약대로 디스크 저장 대상이 아님      |
| 새 농장/저장 불러오기   | 기존 덮어쓰기 확인 유지. 취소 시 기존 농장 보존                               |
| 메인 표시 중            | 논리 일시정지, 가려진 병력의 GameKit WebGL 그리기 호출 없음                   |

저장 관리(내보내기/불러오기)는 펼침 영역에 두며 저장 오류·잠금 해제·업데이트·설치·기존 소개 기능의 소유자를 유지합니다. 저장이 잠기면 새 농장/이어가기/불러오기는 비활성화되고 기존 기록 삭제 확인만 명시적으로 제공합니다.

## 디자인 근거

2026-11-02 [바운코](https://byh-playground.github.io/bloom-bounko/)와 [블룸 발배구](https://byh-playground.github.io/bloom-takraw/)의 공개 화면을 1280×720에서 직접 확인했습니다. 바운코의 시작/보조 기능 위계와 발배구의 큰 제목·왼쪽 시작 동선·오른쪽 대표 장면 구성을 비교했습니다. 조회 기준 source는 바운코 `d230904bb6d40d18dc022dc79154ab01f7a93050`, 발배구 `27bb6d5dd4746e0c9f4e205618776f0c2dfca178`입니다(AI-003·AI-004).

버드몰이의 크림·세이지·잉크 팔레트와 단색 면을 유지하고 큰 로고, 농장 그림, 실제 병종과 공통 얼굴의 `happy` 표정 원본을 배치했습니다. 그림 원본은 `assets/home-garden.svg` 하나이며 병종 그림은 기존 `speciesFacePortraitSource`를 재사용합니다. 새 게임 시뮬레이션이나 미리 구운 메시·조합 이미지는 없습니다(AI-010). 정적 장식은 입력을 받지 않습니다. 모바일에서는 같은 동선을 세로로 배치하고 667×375 가로 모드에서도 시작 버튼을 첫 화면 안에 둡니다.

## 확인 방법

`npm run test:home`은 데스크톱/390×844 터치/667×375에서 시작·설정·메인·같은 세션 이어가기·새 농장 취소·뒤로/앞으로·내보내기·F5를 실행합니다. 데스크톱은 진행 중인 도전의 인스턴스 보존도 확인합니다. 메인에서 논리 시간 불변과 실제 renderer 메서드 호출 0회를 관찰합니다. 호출 계측 래퍼는 원본에 위임하며 게임 동작을 대체하지 않습니다.

시각 비교는 기준 0.67.9 `e18b33df778c670d1ab59d1cb3b00e2d94b98aa2`와 새 화면을 같은 1280×720·390×844·667×375/DPR1에서 캡처합니다. 메인은 tick0의 정적 UI이며 모델 seed를 사용하지 않습니다. 관찰물은 임시 경로에 두고 PR에 결과만 기록합니다(AI-013·AI-015·AI-016·AI-017). 대표 흐름 검사는 영구 시나리오이며 180초 제한으로 CI에서도 실행합니다.
