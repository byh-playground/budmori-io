# 몸 크기와 투사체 크기

기준 버전: `0.8.2`.

## 하나의 몸 정의

`src/features/unit-body/definition.cjs`는 아홉 종의 중립 자세 몸통 외곽선, 원본 SVG의 지면 소켓,
등급·성장 배율을 함께 정의합니다. 모델의 반경·높이와 병력 표현은 이 정의를 공유합니다.
기존 SVG 아트와 등급별 표시 배율, 카메라 투영은 유지합니다.

몸통은 다음 이름의 실제 Bézier 경로를 측정했습니다. SVG의 모든 상위 transform을 적용한 canvas 좌표이며,
원본의 둥근 외곽 stroke를 포함합니다. 잎·모자·무기·팔·다리·그림자·등급 외곽선은 몸통 크기에 포함하지 않습니다.
땅콩은 중립 자세에서 숨겨지는 열린 껍질과 내부 알을 제외합니다.

| 종     | 몸통 경로             | 성체 T1 반경 | 지면부터 몸통 위 높이 | 몸통 자체 높이 |
| ------ | --------------------- | -----------: | --------------------: | -------------: |
| 콩     | `body-outline`        |     0.344562 |              0.910986 |       0.773510 |
| 옥수수 | `corn-body-outline`   |     0.410624 |              1.259342 |       1.032744 |
| 팥     | `bean-body-outline`   |     0.298306 |              1.242074 |       1.077656 |
| 밤톨   | `chestnut-shell`      |     0.384475 |              0.976863 |       0.863838 |
| 땅콩   | `peanut-pod-outline`  |     0.185966 |              0.829526 |       0.762670 |
| 호두   | `walnut-body-outline` |     0.278058 |              0.815398 |       0.733656 |
| 쌀     | `rice-body-outline`   |     0.258979 |              0.884035 |       0.841682 |
| 밀     | `wheat-grain-outline` |     0.216706 |              1.028701 |       0.968175 |
| 보리   | `barley-seed-outline` |     0.267902 |              0.805926 |       0.722789 |

표의 수치는 월드 단위입니다. 수직 billboard 길이는 기존 높이 투영 계수 `0.785`로 나누어 world z로
환산합니다. 바닥 깊이 계수 `0.62`와 혼용하지 않습니다. 몸통의 좌우가 지면 소켓을 중심으로 비대칭이면
큰 쪽을 반경으로 사용해 기존 원기둥 충돌 모델이 몸통 전체를 포함하게 합니다.

- `Unit.radius`: 지면 소켓 중심의 몸통 수평 반경
- `Unit.height`: 지면부터 몸통 최상단까지의 충돌 높이
- `Unit.bodyHeight`: 몸통 외곽선의 최상단부터 최하단까지의 높이
- `Unit.bodyScale`: 원본 SVG canvas 한 단위의 월드 표시 배율
- `Unit.size`: 기존 표시·그림자 API를 위한 동일 배율의 파생값

유닛의 발달은 기존 표시처럼 50%에서 100%까지 연속 성장합니다. 이전 충돌 반경은 미성체를 80%로
고정했다가 성체에서 바뀌었으므로, 작은 땅콩·밀 유닛의 충돌 영역은 특히 작아집니다. 아트 크기를 바꾸어
과거의 부정확한 충돌 영역에 맞추지 않습니다. 공간 검색의 최대 반경, 레이드 투입 여백과 보스 소환 착지
여백도 같은 정의에서 구합니다.

표현은 기존 전체 SVG 배율을 유지하면서 지면 소켓을 실제 투영 지면에 맞춥니다. 최소 표시 픽셀은
화면에만 적용되며 충돌·이동·저장 상태로 역전파하지 않습니다. 동작의 squash·회전·등급 장식도 표현 전용입니다.

## 옥수수 20%

씨앗탄의 발사 순간 `Unit.bodyHeight × 0.2`를 기존 projectile의 `height`에 기록합니다. 이후 소유자의
성장·합체·제거는 발사된 탄을 확대하거나 축소하지 않습니다. 같은 정의에서 회전한 타원의 실제 수평
외곽 반경을 계산해 `radius`에 기록합니다. 기존 공격 범위 배율을 별도로 곱해 몸·탄의 비율을 바꾸지 않습니다.

표현은 `height × 0.785`를 사용하고 기존 타원 비율과 `0.3` 라디안 기울기를 보정하여, 기울어진 낟알의
실제 화면 높이가 중립 몸통 높이의 20%가 되게 합니다. 유닛에 최소 픽셀 확대가 적용되면 발사 당시 몸
크기에서 계산한 같은 확대율을 낟알과 그림자에 적용합니다. 타격 원기둥의 z는 하단이며 표시 하단도 같은
높이에 놓입니다. 꼬리·빛 반사·애니메이션 변형·등급 장식은 20% 측정에 포함하지 않습니다.

착지한 팝콘 낟알은 기존의 납작한 자세를 유지하되, 수평 범위와 그림자를 동일한 발사 반경에서 구합니다.
폭발 범위·신관 시간·연쇄 처리 순서는 바꾸지 않습니다. 가시적인 공중 높이와 world z를 혼용하지 않습니다.

## 저장과 원본 검증

몸 크기는 런타임 getter로 파생하며 새 Unit 저장 필드를 추가하지 않습니다. 기존 compact 진행 저장과
지원되는 구버전 저장을 복원하면 현재의 몸 정의가 적용됩니다. 진행 중인 투사체는 이미 존재하던
`radius`·`height` 필드로 발사 크기를 보존합니다.

기존 SVG 원본 검증에서 아홉 몸 정의의 원본 파일 경로와 SHA256을 함께 확인합니다. 원본이 바뀌면
몸통 경로·상위 transform·지면 소켓을 재확인하고 정의의 근거를 갱신해야 빌드할 수 있습니다. 컴파일된
메시를 저장하거나 모델에서 DOM·렌더러를 읽지 않습니다.

검증은 기존 시작·저장·SVG·린트 빌드 경로와 일회성 모델/표현 검사를 사용합니다. 원본 SVG의 실제
GameKit draw packet 비교는 아트 배율·동작 유지와 지면 이동을 확인하는 CPU 검사이며, 브라우저/GPU
화면 검증을 대신하지 않습니다.
